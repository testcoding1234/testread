📚 Reading Journal - Manual Test Suite

✅ Feature Tests

🎨 Visual Features

Star Rating System

Open the app and add a book, then rate it:

  • Empty stars should be gray (☆)
  • Filled stars should be gold (★)
  • Tapping instantly updates rating
  • Large touch targets (48px minimum)

Smart Tag Suggestions

Add a book and go to the tags section:

  • Auto-suggested tags appear below input
  • Type in tag input to see autocomplete dropdown
  • Can select suggested or create custom tags
  • Tags extracted from title, author, categories

Google Drive Setup Guide

Access the setup guide:

  • Menu (☰) → "Settings & Google Drive Setup"
  • Click "Show Google Drive Setup Guide"
  • Step-by-step instructions are clear and detailed
  • Privacy information is visible
  • Can save Client ID in settings
